# Presentation Suite

Designed, integrated, refactored, and continuously maintained by **TIKAZ**.

Choose exactly one builder:

- `html-deck-builder` for browser-editable HTML and export workflows.
- `powerpoint-deck-builder` for native editable PPTX.
- `magazine-web-deck` for the specific magazine or Swiss-style single-file web deck.

Do not run multiple builders for the same final deck unless the user explicitly requests parallel format variants.

Every builder shares the same narrative brief, page contract, source/license record, and render QA gate.
