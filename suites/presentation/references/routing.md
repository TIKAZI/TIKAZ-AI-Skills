# Routing

- Browser-editable HTML, interactive preview, HTML/PDF export → `html-deck-builder`.
- Native editable PPTX, charts, tables, notes, template reuse → `powerpoint-deck-builder`.
- Editorial magazine or Swiss-style single-file web deck → `magazine-web-deck`.

Choose one final builder unless the user explicitly asks for separately verified format variants.

Examples:
- Example: “Make an offline browser-editable HTML deck for a product demo.”
- Example: “Create an editable PPTX from this brief and inspect rendered overflow.”
- Example: “Turn this essay into a Swiss-style single-file web presentation.”
