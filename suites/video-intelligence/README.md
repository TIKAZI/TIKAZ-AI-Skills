# Video Intelligence Suite

Designed, integrated, refactored, and continuously maintained by **TIKAZ**.

Primary skill: `video-platform-reader`.

Flow: identify source → acquire lawful evidence → transcript/Whisper fallback → keyframe review → source verification → single-video card → cross-video synthesis.

Use knowledge or writing skills only after the video evidence is established.

Its differentiator is evidence grading: a title, transcript, keyframe, and verified primary source are never treated as equivalent evidence.
