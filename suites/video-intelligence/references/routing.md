# Routing

- Video URL or local media → `video-platform-reader`.
- Literature or official-source verification → hand off verified claims to `academic-research` only when needed.
- Personal memory capture → hand off final evidence records to `personal-knowledge-memory`; never store credentials or raw private media.
- Writing cleanup → use `concise-writing-editor` after evidence is stable.

Examples:
- Example: “Compare these Bilibili and YouTube tutorials with timestamps and mark visual claims.”
- Example: “Read this local lecture and produce evidence cards, not a generic summary.”
- Example: “Synthesize three videos and show conflicts before recommending a workflow.”
