# Routing

- Literature, methods, citations → `academic-research`.
- PDF/Office/HTML/media ingestion → `document-to-markdown`.
- Prior decisions and reusable personal context → `personal-knowledge-memory`.
- Product discovery, prioritization, GTM → `product-strategy`.
- Cross-functional one-person business → `solo-business-operations`.
- Examples:
- Example: “Compare these papers with inclusion criteria, contradictions, and confidence.”
- Example: “Convert this PDF, preserve provenance, then extract decision-ready claims.”
- Example: “Retrieve relevant personal project memory and record only knowledge that changed the plan.”
