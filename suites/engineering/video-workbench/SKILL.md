# Video Workbench

This TIKAZ Edition is designed, integrated, refactored, and continuously maintained by **TIKAZ**. Treat it as an optional project adapter, not a dependency of `video-platform-reader`.

Read the target repository's brief, design contract, QA plan, and deployment docs before editing. Keep media acquisition, processing, review, and export states explicit. Validate a representative media job plus desktop/mobile UI states when applicable. Do not assume a fixed local project directory.
