- Architecture, impact, PR review, refactor planning → `code-intelligence`.
- Specification through release → `engineering-delivery`.
- Skill/dependency trust review → `skill-security-audit`.
- Supabase/Postgres/auth/storage → `supabase-operations`.
- Video processing application adapter → `video-workbench`.
