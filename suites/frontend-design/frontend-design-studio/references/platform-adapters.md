# 平台适配路线

## Web 首版

首版把网页作为实现真源，但只复用可迁移的语义：颜色、字体角色、间距、层级、组件状态、动效目的、时长、缓动和降级策略。不要把 DOM、CSS 类名或某个 Vue/React 动效组件当作跨平台规范。

## PWA

优先复用 Web 实现。补充离线、安装、权限、返回行为、安全区、触控和弱网状态。验证移动浏览器视口与 standalone 模式。

## Tauri / Electron EXE

可以复用 HTML/CSS/JS 与多数 Web 动效，但必须重新检查窗口缩放、系统字体、标题栏、拖拽区、键盘快捷键、文件系统权限、高 DPI、GPU/WebView 差异、离线启动和打包体积。持续 WebGL 与透明窗口组合要在目标机器实际测试。

## React Native / Flutter / SwiftUI / Android 原生

不要移植 Vue Bits 或 DOM 源码。迁移行为规格：触发、起止状态、持续时间、缓动、层级、手势、中断规则、reduced-motion/系统动画设置。按平台选择原生动画和组件，保持平台导航、返回、键盘、触觉和安全区惯例。

## 设计契约扩展

在 `DESIGN.md` 的 platform notes 中为每个平台写：

- 可直接复用的 tokens。
- 需要重新实现的组件和动效。
- 平台原生惯例优先于品牌表达的部分。
- 输入方式、窗口/屏幕、性能和无障碍差异。
- 对应的真实设备或打包验收清单。
