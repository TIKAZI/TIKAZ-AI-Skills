# Routing

- New build, redesign, critique, bolder/distill/polish → `frontend-design-studio`.
- Dependency and cross-file impact → `code-intelligence`.
- Implementation lifecycle and release → `engineering-delivery`.
- Third-party skill or component uncertainty → `skill-security-audit` plus license review.

Only one skill owns the visual direction.
- Examples:
- Example: “Redesign this landing page and approve a desktop/mobile art-direction proof first.”
- Example: “Audit this dashboard for generic visual patterns without turning it into a marketing page.”
- Example: “Adapt the approved web design to an Electron shell and verify responsive states.”
