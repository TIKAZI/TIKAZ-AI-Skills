# Visual Content Suite

Designed, integrated, refactored, and continuously maintained by **TIKAZ**.

Choose exactly one illustrator:

- `xiaohei-article-illustrator` for surreal hand-drawn Chinese article visuals.
- `zhuge-logistics-illustrator` for logistics explainers and information cards.

Use `concise-writing-editor` before illustration when copy is generic or padded. Use `legal-free-music` only for lawful music discovery. `生图-Image2` is not included.

The suite is provider-neutral: visual direction, provenance, accessibility, and publishing-size QA remain useful even when the image tool changes.
