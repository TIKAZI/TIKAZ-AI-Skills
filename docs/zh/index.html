系统架构

一个规范源。
七个独立入口。

Monorepo 负责架构、来源、校验与跨套件移交；七个分发仓库由它自动生成，使每套工作流都能被独立发现、收藏、克隆和安装，又不会变成八份逐渐漂移的代码。

  1. 01一个套件负责最终交付物。

    专业 Skill 提供支持，不争夺控制权。

  2. 02证据跟随工作流移动。

    来源、置信度、许可证和未解决问题不会在移交时消失。

  3. 03客观质量门关闭循环。

    渲染、测试、文件与程序状态高于代理自信。

工作流合集

七套工作流，可以组合，也可以单独安装。

01 / 旗舰

Frontend Design

覆盖艺术指导、实现、审查、响应式 QA 与工程移交，帮助产品形成一致且有辨识度的视觉世界。

页面类型 → Design Read → 样板 → 实现 → 视觉 QA
↗
02 / 旗舰

Video Intelligence

把元数据、字幕、ASR、关键帧、外部核验和推断保持在不同证据层级。

来源 → ASR → 关键帧 → 证据卡 → 综合
↗
03 / 证据优先

Context Economy

生成有预算、可恢复、可审计的上下文，把节省、保真和待验证能力分开报告。

Pack → Checkpoint → Audit → Benchmark
↗
04

Engineering

从规格、影响分析到实现、测试、安全审查与发布证据。

范围 → 影响 → 代码 → 测试 → 发布
↗
05

Knowledge & Research

来源规范化、证据台账、分歧、置信度、产品决策和个人知识反馈。

问题 → 来源 → 证据 → 决策
↗
06

Presentation

叙事优先的 HTML、可编辑 PPTX 和杂志型网页演示，并要求渲染 QA。

叙事 → 格式 → 页面 → 渲染 → 产物
↗
07

Visual Content

不绑定供应商的配图方向、精简写作、合法音乐、无障碍文本与发布 QA。

观点 → 风格 → Shot Card → 制作 → 验证
↗
