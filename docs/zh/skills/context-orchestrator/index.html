它解决什么

在默认无依赖 Economy 与显式 ON 本地 On-Premise 之间路由，并统一命中、保真与成本合同。

02

适合何时使用

当这一项明确能力就是你的完整目标时，直接安装并调用它；需要跨能力端到端结果时，改用所属工作流编排器。

03

独立安装

只复制这个 Skill 文件夹即可；不需要安装同组其他 Skill。目标文件夹名称保持与 Skill 名称一致。
Copy-Item -Recurse -LiteralPath '.\suites\context-economy\context-orchestrator' -Destination '.\.agents\skills\context-orchestrator'
